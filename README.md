# Mon premier projet Git

## Présentation

Ce dépôt est mon premier projet réalisé pour apprendre Git et GitHub.

J'ai créé ce projet sur mon ordinateur, appris à suivre les modifications de mes fichiers et publié mon premier commit sur GitHub.

## Compétences pratiquées

- Installation et configuration de Git
- Création d'un dépôt local avec `git init`
- Préparation des fichiers avec `git add`
- Enregistrement des versions avec `git commit`
- Connexion à un dépôt distant avec `git remote`
- Publication sur GitHub avec `git push`

## Objectif

Continuer à progresser en Git et GitHub afin de documenter et publier mes futurs projets en réseaux informatiques et en cybersécurité.
